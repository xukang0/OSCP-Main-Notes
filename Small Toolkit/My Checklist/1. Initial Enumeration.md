## 01. Initial NMAP Enumeration

Compile a list of accessible hosts and add it to a `hosts.txt` file.

`-iL hosts.txt`

Full TCP Scan
```dataviewjs
const page = dv.page("Synced OSCP Notes/Top/Active Machine");const ip = page?.IP ?? "NO IP FOUND";

const command = `sudo nmap -A -Pn -T4 -p- --open -oA fulltcp_scan ${ip}`;

dv.paragraph("```bash\n" + command + "\n```");
```
UDP Scan
```dataviewjs
const page = dv.page("Synced OSCP Notes/Top/Active Machine");const ip = page?.IP ?? "NO IP FOUND";

const command = `sudo nmap -sU -T4 --top-ports 100 -oA udp_scan ${ip}`;

dv.paragraph("```bash\n" + command + "\n```");
```

Add hosts to /etc/hosts 
```dataviewjs
const page = dv.page("Synced OSCP Notes/Top/Active Machine");const ip = page?.IP ?? "NO IP FOUND";

const discoveredDomain = page?.["Discovered Web Domain"] ?? "NO DOMAIN FOUND";

const command = `echo "${ip} ${discoveredDomain}" | sudo tee -a /etc/hosts`;

dv.paragraph("```bash\n" + command + "\n```");
```
