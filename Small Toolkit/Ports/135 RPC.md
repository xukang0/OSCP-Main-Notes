# Net RPC Cmds
# 1. Enumerate domain users

List domain users

```
net rpc user -U 'DOMAIN/USER%PASSWORD' -S DC_IP
```

View information about a specific user

```
net rpc user info USERNAME -U 'DOMAIN/USER%PASSWORD' -S DC_IP
```

# 2. Enumerate domain groups

List domain groups

```
net rpc group -U 'DOMAIN/USER%PASSWORD' -S DC_IP
```

List members of a specific group

```
net rpc group members "Domain Admins" -U 'DOMAIN/USER%PASSWORD' -S DC_IP
```

Other useful groups to enumerate:

```
net rpc group members "Domain Users" -U 'DOMAIN/USER%PASSWORD' -S DC_IP

net rpc group members "Domain Admins" -U 'DOMAIN/USER%PASSWORD' -S DC_IP

net rpc group members "Enterprise Admins" -U 'DOMAIN/USER%PASSWORD' -S DC_IP

net rpc group members "Account Operators" -U 'DOMAIN/USER%PASSWORD' -S DC_IP

net rpc group members "Backup Operators" -U 'DOMAIN/USER%PASSWORD' -S DC_IP

net rpc group members "Server Operators" -U 'DOMAIN/USER%PASSWORD' -S DC_IP
```

Important: `net rpc group members` enumerates domain group membership. It is not the same as enumerating local groups on a member machine.

# 3. Enumerate shares

For share enumeration, use `net rpc`'s share command:

```
net rpc share list -U 'DOMAIN/USER%PASSWORD' -S TARGET_IP
```

# 4. Password operations

Change a domain user's password

```
net rpc password USERNAME 'NewPassword123!' \
-U 'DOMAIN/ADMINUSER%ADMINPASSWORD' \
-S DC_IP
```

Here:

- `USERNAME` = account whose password you want to change.
    
- `DOMAIN` = AD domain.
    
- `ADMINUSER` = account performing the operation.
    
- `DC_IP` = Domain Controller IP.
    

Requires appropriate password-change or reset permissions.

# 5. Group membership operations

Add a user to a domain group

```
net rpc group addmem "GROUPNAME" USERNAME \
-U 'DOMAIN/ADMINUSER%ADMINPASSWORD' \
-S DC_IP
```

Remove a user from a domain group

```
net rpc group delmem "GROUPNAME" USERNAME \
-U 'DOMAIN/ADMINUSER%ADMINPASSWORD' \
-S DC_IP
```

These operations require sufficient permissions over the group.

# 6. Account operations

Create a domain user

```
net rpc user add USERNAME PASSWORD \
-U 'DOMAIN/ADMINUSER%ADMINPASSWORD' \
-S DC_IP
```

Delete a domain user

```
net rpc user delete USERNAME \
-U 'DOMAIN/ADMINUSER%ADMINPASSWORD' \
-S D
```
