So after modifying a service within:
```
ls -la /etc/systemd/system/
```

you usually run:
```
sudo systemctl daemon-reload
```

which tells systemd:

> “Reload all unit files from disk and rebuild the dependency tree.”

Then:
```
sudo systemctl restart [service].service
```
starts the service using the updated definition.
